## 🚀 How to Deploy to GitHub Pages (No Coding Required!)

### Step 1: Create a GitHub Account (if you don't have one)
1. Go to [github.com](https://github.com)
2. Click "Sign Up" and create a free account
3. Verify your email address

### Step 2: Create a New Repository
1. Click the **+** icon in the top right corner
2. Select **"New repository"**
3. **IMPORTANT**: Name your repository exactly: `yourusername.github.io`
   - Replace `yourusername` with your actual GitHub username
   - Example: If your username is `aishwaryapandey`, name it `aishwaryapandey.github.io`
4. Make sure it's set to **Public**
5. Check the box that says **"Add a README file"**
6. Click **"Create repository"**

### Step 3: Upload Your Files
1. In your new repository, click **"Add file"** → **"Upload files"**
2. Drag and drop the `index.html` file into the upload area
3. Scroll down and click **"Commit changes"**

### Step 4: Enable GitHub Pages
1. Go to your repository **Settings** (gear icon tab)
2. Scroll down to **"Pages"** in the left sidebar
3. Under "Source", select **"main"** branch
4. Click **Save**
5. Wait 2-3 minutes for deployment

### Step 5: Visit Your Live Site!
Your website will be live at: `https://yourusername.github.io`

## 🎨 Customization Guide

### To Update Your Information:
Open `index.html` in any text editor (Notepad, TextEdit, VS Code) and search/replace:

| Find | Replace With |
|------|-------------|
| `aishwaryapandey1094@gmail.com` | Your email |
| `617-858-9509` | Your phone |
| `https://www.linkedin.com/in/aishwaryapandey10/` | Your LinkedIn URL |
| `San Francisco Bay Area` | Your location |

### To Add Your Resume:
1. Save your resume as `Aishwarya_Pandey_Resume.pdf`
2. Upload it to the same GitHub repository
3. The "Download Resume" button will automatically link to it

### To Change Colors:
At the top of the `index.html` file, find the `:root` section with CSS variables:

```css
:root {
    --ink: #1a1a2e;        /* Dark text/backgrounds */
    --cream: #faf8f5;      /* Light background */
    --gold: #c9a227;       /* Accent color */
    --slate: #4a4a5a;      /* Secondary text */
    --accent: #2d4a3e;     /* Green accent */
}
```

Change these hex color codes to customize the look.
